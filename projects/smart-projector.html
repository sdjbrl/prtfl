Smart Projector IRIS

📅 5 jan — 13 fév 2026

Documentation technique

Automatisation des vidéoprojecteurs des salles de classe IRIS Nice pour simplifier l'usage quotidien par les formateurs. Problématique : allumage/extinction manuelle chronophage, gestion des sources HDMI complexe, pas de centralisation. Solution : Raspberry Pi 4 + relais pour contrôle alimentation + commutation HDMI automatique. Interface web locale pour contrôle à distance depuis les postes enseignants.

Phase 1 : Analyse des besoins (10 salles, 3 sources HDMI par salle) → Phase 2 : Choix matériel (Raspberry Pi 4 2GB, module relais 4 canaux, switch HDMI 3→1) → Phase 3 : Développement interface web (Python Flask + GPIO control) → Phase 4 : Déploiement pilote sur 2 salles → Phase 5 : Rollout complet avec documentation formateurs.

Compétences BTS SIO SISR mobilisées

Gérer le patrimoine informatique Mettre à disposition des utilisateurs un service informatique Travailler en mode projet Répondre aux incidents et aux demandes d'assistance et d'évolution

Livrables

Critères d'évaluation

Contrôle à distance depuis les postes enseignants
Commutation HDMI automatique (3 sources)
Temps de réponse < 2 secondes
Adoption formateurs validée

Modalités de clôture

// Infrastructure réseau — Stage IRIS Mediaschool Nice

Smart Projector IRIS

📅 4 jan — 13 fév 2026 · Stage

Documentation technique

Réalisation effectuée dans le cadre du stage de 6 semaines à IRIS Mediaschool Nice (4 jan — 13 fév 2026). Automatisation des vidéoprojecteurs des salles de classe pour simplifier l'usage quotidien par les formateurs. Problématique remontée en début de stage via recueil de besoins informel (approche ITIL : gestion des demandes de service) — allumage/extinction manuelle chronophage, gestion des sources HDMI complexe, pas de centralisation. Solution : Raspberry Pi 4 + relais pour contrôle alimentation + commutation HDMI automatique. Interface web locale pour contrôle à distance depuis les postes enseignants.

Phase 1 : Analyse des besoins (10 salles, 3 sources HDMI par salle) → Phase 2 : Choix matériel (Raspberry Pi 4 2GB, module relais 4 canaux, switch HDMI 3→1) → Phase 3 : Développement interface web (Python Flask + GPIO control) → Phase 4 : Déploiement pilote sur 2 salles → Phase 5 : Rollout complet avec documentation formateurs.

Gestion des risques

Risque identifiéProbabilitéImpactMesure de mitigation
Panne du Raspberry Pi (surchauffe, alimentation défectueuse) Moyenne Élevé Boîtier ventilé + alimentation officielle + image SD de remplacement prête à flasher en < 10 min
Incompatibilité GPIO — relais activé sans commande (sécurité électrique) Moyenne Élevé Tests de câblage sur banc avant installation en salle + état par défaut des relais sur OFF (NO)
Interface web inaccessible (réseau WiFi instable en salle) Moyenne Moyen Connexion Ethernet filaire du Raspberry Pi au réseau IRIS + adresse IP statique documentée
Non-adoption par les formateurs (complexité interface) Faible Moyen Interface réduite à 3 boutons (ON/OFF/Source) + guide formateurs d'une page distribué en salle

Le code source (Flask + scripts GPIO) est versionné sur Git, permettant un redéploiement depuis zéro sur tout Raspberry Pi 4 en moins de 10 minutes (flash SD + git clone + systemctl start projector). En cas de panne totale du système, les projecteurs restent utilisables manuellement via télécommandes IR, garantissant la continuité pédagogique.

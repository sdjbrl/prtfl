// Administration système — Projet scolaire

Windows Server

📅 Déc 2025

Documentation technique

Réponse à un appel d'offre scolaire : automatisation complète d'une infrastructure Windows Server pour établissement scolaire via Vagrant. Déploiement de 3 VMs (SRV-DC1, SRV-FS1, CLIENT-WIN11) sur un réseau privé 192.168.100.0/24. Rôles déployés : AD DS (domaine mediaschool.local, 8 OU, 3 groupes), DNS, DHCP, GPO, FSRM (quotas par profil), WSUS, WDS. Infrastructure déployable en ~45 min via une seule commande Vagrant.

Infrastructure as Code avec Vagrant (VirtualBox) : provisioning séquentiel DC → FS → Client via 10 scripts PowerShell idempotents. Approche itérative : TP manuel converti en déploiement automatisé (gain de 85% de temps). Validation à chaque étape (ping, résolution DNS, baux DHCP, jonction domaine, accès partages, WSUS port 8530).

Compétences BTS SIO SISR mobilisées

Critères d'évaluation

Infrastructure déployée en < 45 min
AD DS fonctionnel (domaine, OU, groupes)
DNS/DHCP/GPO opérationnels
FSRM quotas actifs
Jonction CLIENT-WIN11 au domaine

Modalités de clôture

Démonstration via vagrant up (commande unique). Recette complète : ping, DNS, DHCP, jonction domaine, partages, WSUS.
